# Updater Configuration

## Tauri Updater Setup

The application uses Tauri's built-in updater for automatic updates.

### Configuration

- **Updater enabled**: See `gui/src-tauri/tauri.conf.json` - `tauri.allowlist.updater`
- **Update endpoints**: Uses GitHub Releases for update detection
- **Platforms**: Linux (AppImage, Deb, RPM)

### How it works

1. App checks for updates on startup (configurable interval)
2. If update available, prompts user to download/install
3. Uses GitHub Releases with `v*` tag pattern
4. Update manifests are automatically generated by Tauri CLI

### For developers

To sign updates, set up the updater private key:

```bash
# Generate keypair (one-time setup)
cd gui
npm run tauri signer generate -w $HOME/.tauri/mykey.key

# Build with signing
TAURI_PRIVATE_KEY="..." npm run tauri build
```

### GitHub Releases setup

Ensure your release workflow (`.github/workflows/build-linux.yml`) creates proper release artifacts that Tauri's updater can parse.

### Endpoints

- **Latest release check**: `https://github.com/4shil/agent-sandbox/releases/latest`
- **Update manifest**: Generated automatically by Tauri during `tauri build`
